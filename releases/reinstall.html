Molly: one-time reinstall

Molly normally updates herself. Very occasionally a new version needs a newer app (for example a new voice engine), and then the app has to be rebuilt once. Your matters, settings and sign-ins are kept.

  1. Quit Molly (menu-bar icon → Quit).
  2. In Terminal, in your Molly folder:
    git pull
./build.sh
  3. Open the new disk image in Downloads and drag Molly to Applications, choosing Replace.
  4. Open Molly. If macOS asks, allow the microphone once.

If Molly was set up for you by someone else, ask them to send you the new version.
